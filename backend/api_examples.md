# API Examples for Senescence Agent Backend

This document contains examples for interacting with the FastAPI backend. You can use these to test the LLM agent without the frontend.

## Base URL
Ensure the FastAPI server is running (usually `http://localhost:8000`).

---

## 1. Upload Dataset (`/upload`)
Upload an `.h5ad` file and receive a `file_id`.

### cURL
```bash
curl -X POST "http://localhost:8000/upload" \
  -H "accept: application/json" \
  -H "Content-Type: multipart/form-data" \
  -F "file=@/path/to/your/dataset.h5ad" \
  -F "species=mouse"
```

### Postman
- **Method**: POST
- **URL**: `http://localhost:8000/upload`
- **Body**: `form-data`
  - `file`: Select file type, attach your `.h5ad` file
  - `species`: Text, e.g. `mouse` or `human`

**Response Example:**
```json
{
  "file_id": "b3c97e1a-83b6-49a3-9529-5d204a37bfa2"
}
```

---

## 2. Chat with Agent (`/chat`)
Send a message to the agent using the `file_id` received from the upload step.

### cURL
```bash
curl -X POST "http://localhost:8000/chat" \
  -H "accept: application/json" \
  -H "Content-Type: application/json" \
  -d '{
    "session_id": "session-1234",
    "message": "Can you score the senescence using the SenMayo signature?",
    "file_id": "b3c97e1a-83b6-49a3-9529-5d204a37bfa2",
    "species": "mouse"
}'
```

### Postman
- **Method**: POST
- **URL**: `http://localhost:8000/chat`
- **Body**: `raw` (JSON)
```json
{
  "session_id": "session-1234",
  "message": "Can you score the senescence using the SenMayo signature?",
  "file_id": "b3c97e1a-83b6-49a3-9529-5d204a37bfa2",
  "species": "mouse"
}
```

**Response Example:**
```json
{
  "reply": "This is a mock response from the agent for a mouse dataset. I am processing your message: 'Can you score the senescence using the SenMayo signature?'.",
  "plots_generated": []
}
```

---

## 3. View Generated Plots (`/plots/{filename}`)
Fetch the PNG outputs generated by Scanpy tools.

### cURL
```bash
curl -O "http://localhost:8000/plots/umap.png"
```

### Browser/Postman
- **URL**: `http://localhost:8000/plots/umap.png`
