# Evaluation Result Status

## Paper-use boundary

The artifacts under `ablation/` are historical development results. They were
generated before the current planner, routing, covariate, confounding,
replicate-stability, provenance, and output-labeling behavior was finalized.

**Do not pool, quote, or present values from `ablation/` as final performance of
the current agent.** They are retained only for development history, debugging,
and auditability.

The authoritative artifact-level classification is recorded in:

- `ablation/RESULTS_INDEX.md`
- `ablation/RESULTS_REGISTRY.csv`

Only artifacts deliberately placed under `final_candidate/` after a protocol
and completeness review may be considered for the paper. Placement there means
"candidate for review," not automatically "approved for publication."
