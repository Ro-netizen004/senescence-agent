CONFOUNDING CHALLENGE SUITE (added 2026-08-13)
==============================================

Purpose
-------
Test the confounding gate as a precision/recall problem, not a single easy case.
The original `confounded` design used a perfect copy of the group column, which
is the trivially easiest confound to detect. Rigor requires (a) recall on real
confounds, (b) a detection boundary, and (c) a specificity arm proving the gate
does not simply block everything.

Designs and expected governed outcome
-------------------------------------
Verified on Kidney fenestrated cell, stratified mode, via sample-level
null_batch x null_group cross-tabs:

  design                null_batch vs fake group     expected gate       tests
  valid                 no covariate                 run (descriptive)   pseudorep baseline
  confounded            perfect separation           BLOCK               recall (easy)
  confounded_partial    imperfect (one flipped)      run (not blocked)   detection boundary
  covariate_balanced    balanced (level in both)     run (not blocked)   specificity
  per_cell_sample       1-cell "samples"             BLOCK               replicate quality
  one_sample_per_group  1 sample per group           BLOCK               insufficient replicates

Confounding-gate confusion matrix
---------------------------------
  confounded BLOCKED          = true positive  (correct refusal)
  confounded NOT blocked      = false negative (missed confound)
  covariate_balanced allowed  = true negative  (correct; no over-refusal)
  covariate_balanced BLOCKED  = false positive (over-refusal bug)
  confounded_partial          = boundary probe; the current perfect-separation
                                gate is expected to ALLOW it. A partial confound
                                the gate misses is a reportable limitation, not a
                                pass/fail, and motivates a partial-separation
                                threshold as future work.

- confounded -> BLOCKED confirmed (2/2 perms, current code): recall holds for the
  perfect case.
- confounded_partial and covariate_balanced constructed and separation-verified
  (imperfect and balanced respectively); governed agent runs across cell types
  and the ungoverned contrast arm are pending.

REPLICATE-STABILITY LICENSING GATE (added 2026-08-14)
======================================================

91. Added a deterministic leave-one-donor-out replicate-stability assessment
    for every DESeq2 result containing FDR-significant genes.
92. The assessment uses pseudobulk counts already held in memory and does not
    refit DESeq2. Counts are converted to log2(CPM+1) using each donor's full
    tested-gene library size, and comparison-minus-reference effects are
    recomputed after omitting each biological donor once.
93. A significant gene is classified as stable only when its effect direction
    is unchanged for every donor omission and its smallest absolute omitted
    effect retains at least 50% of the full-data log2-CPM effect.
94. A result passes the stability gate when at least 80% of its FDR-significant
    genes are stable. The output records the stable fraction, median minimum
    effect retention, per-gene stability details, sample counts, method, and all
    prespecified thresholds.
95. Stability requires at least four biological donors per contrast group. With
    fewer donors, removing one would fall below the existing three-per-group
    DESeq2 admissibility minimum; the result is marked insufficient_evidence and
    cannot be licensed inferentially.
96. Added inference-state downgrades and validity flags. unstable results receive
    replicate_instability; insufficient or failed assessments receive
    replicate_stability_not_established. Either condition forces
    DESCRIPTIVE_ONLY and removes the inferential conclusion.
97. Extended the strict output firewall so stability-failed analyses expose no
    gene rows or download link. The renderer explains that donor stability was
    not established without presenting the withheld genes.
98. Split evaluation accounting into result_withheld_rate (any gate),
    stability_withheld_rate, and plausibility_withheld_rate. The null harness
    now preserves the complete replicate_stability audit in each permutation.
99. Updated single- and multi-tissue Markdown/CSV reporting to show overall,
    stability-specific, and plausibility-specific withholding separately.
100. Added synthetic regression tests for a consistent four-vs-four donor
     effect, a single-donor-driven effect, and an unassessable three-vs-three
     design, plus inference-state, audit-preservation, and output-firewall tests.
101. Ran a real Liver hepatocyte seed-1500 allocation that previously resembled
     the licensed null failures: DESeq2 found 10 genes and the plausibility gate
     returned ok, but the new stability gate downgraded the result to
     DESCRIPTIVE_ONLY with no licensed claim.

Interpretive boundary
---------------------

it is not a second p-value calculation and does not prove a causal effect. The

cell types, positive controls, and a many-donor UMI dataset. The seed-1300 files

METHOD-INVARIANCE: SECOND DE METHOD (added 2026-08-13)
======================================================

Purpose
-------
Demonstrate that the validity governance is a property of the statistical
unit/design, not of one DE implementation, to pre-empt the reviewer objection
that the firewall is specific to DESeq2. A second replicate-aware pseudobulk DE
method is added that runs through the IDENTICAL build_pseudobulk and Gate 1.

108. Added backend/tools/run_nbglm.py, a pseudobulk negative-binomial GLM DE
     method (edgeR family). It is drop-in compatible with
     run_deseq2.run_deseq2_pseudobulk: same pseudobulk count matrix and metadata
     in, same results columns out, so the governance path is unchanged and only
     the DE tool differs.
109. Labeled honestly. It is an edgeR-FAMILY method (NB-GLM), NOT edgeR itself.
     edgeR is R-only and rpy2/R are not installed here; the module docstring says
     so. It also does not use DESeq2-style log-fold-change shrinkage.
110. First implementation used a single common dispersion and a Wald test and was
     markedly anti-conservative on a stratified 3v3 null: 1,632 null discoveries
     versus DESeq2's 254 on the identical pseudobulk. Cause: one common
     dispersion under-models high-variance genes, and the Wald test is
     anti-conservative at ~4 residual degrees of freedom.
111. UPGRADE (path A): replaced the common dispersion with a mean-trended
     per-gene dispersion and the Wald test with a likelihood-ratio test. This
     improved the same stratified 3v3 null from 1,632 to 957 null discoveries,
     but NB-GLM remains markedly more anti-conservative than DESeq2 (254 on the
     identical pseudobulk).
112. Honest limit recorded: the residual gap is exactly the machinery only real
     edgeR has -- empirical-Bayes tagwise dispersion moderation and a
     quasi-likelihood F-test that accounts for dispersion-estimation uncertainty
     at small n. Reimplementing those in Python would be a poor-man's edgeR and
     is out of scope. NB-GLM is kept as an honestly-labeled, fair-but-imperfect
     edgeR-family method.
113. Reframed the method-invariance claim to what the evidence supports: the
     GOVERNANCE is method-invariant by construction (identical build_pseudobulk
     and Gate 1; only the DE tool differs), and BOTH GLM methods over-discover on
     this Smart-seq2 low-n null (254 vs 957) yet are governed identically. Safety
     comes from the deterministic gates, not from any single DE method being
     well-calibrated -- a stronger rebuttal to "DESeq2-specific" than "both
     methods are calibrated" would have been.
114. Clarification for the paper: the "pseudobulk = 0.47 false genes" figure is
     the per-sample t-test (conservative at small n), NOT the GLM methods. DESeq2
     and NB-GLM are both anti-conservative at low n on Smart-seq2 pseudobulk. The
     honest claim is that the statistical UNIT (replicate) fixes the
     pseudoreplication catastrophe, the DE method's small-n calibration varies,
     and the gates are the backstop.
